# AY 2026-27 NPS 80CCD(1B) Deduction Checklist

NPS contributors need a return that can be traced back to the records, not merely a plausible prefilled figure. Start with NPS transaction statement and Form 16, then use PRAN details to settle the classification, credit, deduction, or disclosure at issue.

## NPS contributors: worked check using regime comparison

If NPS transaction statement supports a claim that Form 16 does not, use PRAN details to identify the unsupported condition. Retain regime comparison with the reason for the chosen treatment.

## NPS transaction statement and Form 16: decide the reporting treatment

NPS transaction statement should establish the claimed amount or status, while Form 16 tests a separate condition. Before deciding the return treatment, check PRAN details for a conflicting taxpayer fact.

1. Use NPS transaction statement and Form 16 to settle the reporting treatment.
2. For NPS contributors, record that comparison in the computation before selecting a form or schedule.
3. Document how PRAN details resolves the issue before choosing a form.
4. After reconciling NPS transaction statement, place regime comparison with the computation and acknowledgement.

## NPS transaction statement and Form 16: what each proves

Assign a specific purpose to NPS transaction statement, Form 16, and every other return record. Do not let Form 16 replace the fact established by NPS transaction statement.

| Record | What to verify |
| --- | --- |
| NPS transaction statement | NPS transaction statement should show the amount, date, counterparty, and activity used in the filing working; compare it with Form 16. |
| Form 16 | Form 16 should support salary, perquisites, deductions, and employer TDS; compare it with PRAN details. |
| PRAN details | PRAN details should support the decision to check NPS contribution evidence, tax-regime fit, employer contribution, and deduction limits; reconcile it with regime comparison before filing. |
| regime comparison | Regime comparison should support the decision to check NPS contribution evidence, tax-regime fit, employer contribution, and deduction limits; reconcile it with NPS transaction statement before filing. |

## NPS contributors: reconcile PRAN details

For NPS contributors, resolve any conflict between the claim supported by NPS transaction statement and the condition shown by Form 16. Use PRAN details to test the disputed condition, then retain regime comparison with the chosen treatment.
