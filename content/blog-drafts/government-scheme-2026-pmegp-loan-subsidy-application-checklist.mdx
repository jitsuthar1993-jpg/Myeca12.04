# PMEGP Loan and Subsidy Application Checklist for 2026

A PMEGP finance application can contain every requested upload and still be unreliable when project report, KYC, bank details, and education or category proof if applicable describe different facts. New micro-enterprise applicants should resolve those differences against PMEGP official portal before they submit.

## PMEGP: confirm the live route and applicant fit

The first PMEGP decision is not whether every upload slot can be filled; it is whether the applicant, activity, funding need, and supporting records satisfy the live route, based on the current authority route and the facts shown by project report, KYC, and education or category proof if applicable.

## New micro-enterprise applicants: map project report to education or category proof if applicable

Before converting files for PMEGP, note the issuer, relevant date, applicant details, and supported answer for project report, KYC, bank details, and education or category proof if applicable.

| Record | What it must support |
| --- | --- |
| project report | Verify activity, cost, or funding details from project report, then test the same applicant file against KYC. Save the checked PMEGP application documents 2026 evidence with the final acknowledgement. |
| KYC | KYC should support the live application answer about applicant identity. For PMEGP application documents 2026, use the format and issuing record named in the current authority instruction. |
| bank details | Bank details should support payment-account details exactly as entered. Compare any different name, date, identifier, or status with education or category proof if applicable before submission. |
| education or category proof if applicable | Use education or category proof if applicable for education, institution, course, or training details; use project report separately for activity, cost, or funding details. Resolve any PMEGP application documents 2026 conflict through source-record correction or written clarification. |

## New micro-enterprise applicants: verify the authority route

PMEGP rules can change after a checklist is saved, so new micro-enterprise applicants should reopen the references below and retain the page used to confirm project report and KYC.

| Official reference | What to confirm |
| --- | --- |
| [myScheme - official government scheme discovery portal](https://www.myscheme.gov.in/) | Compare the discovery-page summary with bank details and education or category proof if applicable; let the linked department instructions control the submission. |
| [PMEGP official portal](https://www.kviconline.gov.in/pmegpeportal/pmegphome/index.jsp) | Read the current instructions before upload, then compare the required KYC with bank details in the PMEGP file. |

## bank details conflict: decide before upload

Use bank details only for the fact it proves. If project report and KYC conflict, correct the issuing record or obtain written guidance before submission.

A conflict between project report and KYC can change the application route or outcome. Ask the issuing authority for clarification and keep the response beside bank details.

## education or category proof if applicable case check: reconstruct the answer

Before the finance application, compare the proposed answer with project report and KYC; use bank details only for its stated purpose and retain education or category proof if applicable with the conclusion.

When the portal accepts project report but the applicant's KYC contains a conflicting fact, use the authority's correction channel before completing the finance application.

## PMEGP finance application: evidence limits and retention

New micro-enterprise applicants should not create a second inconsistent PMEGP finance application to bypass a record problem; use the correction or grievance route linked by PMEGP official portal.

PMEGP preparation is complete when project report, KYC, and bank details explain the application facts and education or category proof if applicable preserves the next step.
