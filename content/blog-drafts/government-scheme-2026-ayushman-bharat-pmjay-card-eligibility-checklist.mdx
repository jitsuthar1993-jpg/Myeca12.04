# Ayushman Bharat PM-JAY Card Eligibility Checklist for Families

Ayushman Bharat PM-JAY preparation is a fit-and-evidence decision for families checking health-cover eligibility; the work is to verify beneficiary status, family details, identity records, and hospital-network readiness, compare Aadhaar or accepted ID with ration card, and retain family details and mobile number for follow-up.

## Ayushman Bharat PM-JAY: confirm the live route and applicant fit

Ayushman Bharat PM-JAY preparation should pause until families checking health-cover eligibility can connect the live instruction to Aadhaar or accepted ID, explain the role of ration card, and record whether the identity, status, and requested service are supported without guessing.

## family details conflict: decide before upload

If Aadhaar or accepted ID and ration card disagree, the Ayushman Bharat PM-JAY file no longer demonstrates that the identity, status, and requested service are supported; resolve the source record before relying on family details.

Separate the question answered by Aadhaar or accepted ID from the one answered by ration card. Resolve a material inconsistency before uploading family details.

## Families checking health-cover eligibility: map Aadhaar or accepted ID to mobile number

Ration card should not be used as a substitute for Aadhaar or accepted ID; assign family details and mobile number their own application questions so the Ayushman Bharat PM-JAY service request can be reconstructed later.

| Record | What it must support |
| --- | --- |
| Aadhaar or accepted ID | Use Aadhaar or accepted ID for applicant identity; use ration card separately for household, residence, or address details. Resolve any PMJAY eligibility card 2026 conflict through source-record correction or written clarification. |
| ration card | Ration card belongs in the file because it supports household, residence, or address details. Confirm the issuer, validity, applicant details, and relevant period before relying on ration card. |
| family details | Read family details only for family, guardian, or nominee details. If mobile number points to a different applicant fact, pause the request and resolve that difference first. |
| mobile number | Mobile number should be current, legible, and linked to the same applicant as Aadhaar or accepted ID. Retain the version used for the submission. |

## mobile number case check: reconstruct the answer

Test the Ayushman Bharat PM-JAY service request before portal entry: ask which live instruction is answered by Aadhaar or accepted ID, which fact is confirmed by ration card, and why mobile number belongs with the result.

If the live instructions require a fact not shown by Aadhaar or accepted ID or ration card, obtain the accepted evidence instead of substituting family details. Keep mobile number in the follow-up file.

## Families checking health-cover eligibility: verify the authority route

Before the Ayushman Bharat PM-JAY service request, check the current applicant category, accepted format for Aadhaar or accepted ID, treatment of ration card, and follow-up channel shown by the official references.

| Official reference | What to confirm |
| --- | --- |
| [myScheme - official government scheme discovery portal](https://www.myscheme.gov.in/) | Use the listing to identify the department responsible for Ayushman Bharat PM-JAY; confirm its accepted-record summary against family details and mobile number. |
| [Ayushman Bharat PM-JAY official portal](https://pmjay.gov.in/) | Confirm whether the authority currently accepts ration card for Ayushman Bharat PM-JAY and note any portal, location, or timing restriction. |

## Ayushman Bharat PM-JAY service request: evidence limits and retention

Aadhaar or accepted ID, ration card, family details, and mobile number can establish a reviewable file for Ayushman Bharat PM-JAY, but the current authority conditions still decide eligibility and outcome.

Keep one Ayushman Bharat PM-JAY service request folder containing the checked authority page, Aadhaar or accepted ID, ration card, mobile number, the request acknowledgement, and later communication.
