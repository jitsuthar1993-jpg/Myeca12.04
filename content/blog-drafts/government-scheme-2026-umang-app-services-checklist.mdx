# UMANG App Services Checklist for Taxpayers and Families

An UMANG service request can contain every requested upload and still be unreliable when mobile number, Aadhaar if required, service account details, and document copies describe different facts. Families using government services should resolve those differences against UMANG official portal before they submit.

## UMANG: confirm the live route and applicant fit

UMANG preparation should pause until families using government services can connect the live instruction to mobile number, explain the role of Aadhaar if required, and record whether the identity, status, and requested service are supported without guessing.

## service account details conflict: decide before upload

Use service account details only for the fact it proves. If mobile number and Aadhaar if required conflict, correct the issuing record or obtain written guidance before submission.

When mobile number and Aadhaar if required point to different applicant facts, identify which authority owns the inaccurate record. Correct or clarify that record before using service account details in the service request.

## Families using government services: map mobile number to document copies

The UMANG service request record map begins with mobile number and ends with document copies; Aadhaar if required and service account details should resolve separate questions rather than repeat the same unsupported answer.

| Record | What it must support |
| --- | --- |
| mobile number | Keep mobile number with its issuer and date visible. It should support verification and alert details without contradicting the applicant identity shown by Aadhaar if required. |
| Aadhaar if required | Aadhaar if required is useful only when the application can trace applicant identity back to it. Resolve any incomplete or inconsistent UMANG app services 2026 detail before submission. |
| service account details | Verify the specific fact it contains from service account details, then test the same applicant file against document copies. Save the checked UMANG app services 2026 evidence with the final acknowledgement. |
| document copies | Document copies should support the live application answer about the specific fact it contains. For UMANG app services 2026, use the format and issuing record named in the current authority instruction. |

## document copies case check: reconstruct the answer

UMANG is ready for a case check when families using government services can explain the applicant fact, the accepted source record, the open issue, and the purpose of document copies.

If service account details is current but mobile number is not, identify whether the older record must be corrected or replaced. Retain document copies and the authority response with the final submission.

## Families using government services: verify the authority route

UMANG should be prepared from current official instructions, with mobile number and Aadhaar if required checked against the source that actually controls the submission.

| Official reference | What to confirm |
| --- | --- |
| [myScheme - official government scheme discovery portal](https://www.myscheme.gov.in/) | Use the listing to identify the department responsible for UMANG; confirm its accepted-record summary against service account details and document copies. |
| [UMANG official portal](https://web.umang.gov.in/) | Read the current instructions before upload, then compare the required Aadhaar if required with service account details in the UMANG file. |

## UMANG service request: evidence limits and retention

UMANG may require correction or grievance steps after submission, so families using government services should preserve service account details, document copies, and every message received from the authority.

After the service request, families using government services should monitor the channel shown on the request acknowledgement and preserve every clarification request with document copies.
