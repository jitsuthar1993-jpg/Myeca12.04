# PM-KUSUM Solar Pump Scheme Checklist for Farmers

A PM-KUSUM application can contain every requested upload and still be unreliable when land record, Aadhaar, bank details, and existing pump details describe different facts. Farmers considering solar pumps should resolve those differences against PM-KUSUM official portal before they submit.

## PM-KUSUM: confirm the live route and applicant fit

Before a PM-KUSUM application, farmers considering solar pumps should write down the intended outcome, open [PM-KUSUM official portal](https://pmkusum.mnre.gov.in/landing.html), and decide whether the applicant and every material condition are supported from land record, Aadhaar, and bank details.

## existing pump details case check: reconstruct the answer

Before submission, trace one material PM KUSUM solar pump documents 2026 answer from PM-KUSUM official portal to land record, Aadhaar, and bank details, and record any correction still required.

Test the application answer against land record, Aadhaar, and bank details. If bank details support a different applicant fact, preserve the issue and request clarification before submission.

## Farmers considering solar pumps: map land record to existing pump details

For farmers considering solar pumps, a reliable PM-KUSUM file separates the job of land record from the jobs of Aadhaar, bank details, and existing pump details, then records any missing or contradictory fact before upload.

| Record | What it must support |
| --- | --- |
| land record | Land record should support the live application answer about land, crop, or activity details. For PM KUSUM solar pump documents 2026, use the format and issuing record named in the current authority instruction. |
| Aadhaar | Aadhaar should support applicant identity exactly as entered. Compare any different name, date, identifier, or status with bank details before submission. |
| bank details | Use bank details for payment-account details; use existing pump details separately for land, crop, or activity details. Resolve any PM KUSUM solar pump documents 2026 conflict through source-record correction or written clarification. |
| existing pump details | Existing pump details belong in the file because they support land, crop, or activity details. Confirm the issuer, validity, applicant details, and relevant period before relying on existing pump details. |

## bank details conflict: decide before upload

PM-KUSUM should proceed only after land record and Aadhaar support one answer for the disputed fact; bank details can add evidence but cannot repair an inaccurate issuing record.

Check whether land record and Aadhaar describe the same applicant, period, and activity. If not, pause the application; use bank details only for payment-account details.

## Farmers considering solar pumps: verify the authority route

Use PM-KUSUM official portal to confirm the current route for farmers considering solar pumps, then record which official page answers the remaining bank details and existing pump details questions.

| Official reference | What to confirm |
| --- | --- |
| [myScheme - official government scheme discovery portal](https://www.myscheme.gov.in/) | Confirm the administering authority for PM-KUSUM and its live department link before relying on the eligibility or document summary. |
| [PM-KUSUM official portal](https://pmkusum.mnre.gov.in/landing.html) | Use this page to confirm the deciding authority and required evidence before farmers considering solar pumps rely on Aadhaar. |

## PM-KUSUM application: evidence limits and retention

Farmers considering solar pumps should not create a second inconsistent PM-KUSUM application to bypass a record problem; use the correction or grievance route linked by PM-KUSUM official portal.

If bank details still leave a material answer unsupported, farmers considering solar pumps should pause the application; otherwise retain existing pump details and the application acknowledgement together.
