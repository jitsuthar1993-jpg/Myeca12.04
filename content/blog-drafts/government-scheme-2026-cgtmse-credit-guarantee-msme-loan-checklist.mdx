# CGTMSE Credit Guarantee Checklist for MSME Loans

CGTMSE preparation is a fit-and-evidence decision for MSME borrowers; the work is to understand guarantee-linked loan records, lender process, and business documentation, compare loan application with business KYC, and retain Udyam certificate and financial statements for follow-up.

## MSME borrowers: map loan application to financial statements

MSME borrowers should read loan application, business KYC, Udyam certificate, and financial statements as a connected record set, but preserve the separate purpose and issuing source of each item.

| Record | What it must support |
| --- | --- |
| loan application | Loan application is useful only when the application can trace the specific fact it contains back to it. Resolve any incomplete or inconsistent CGTMSE loan guarantee checklist 2026 detail before submission. |
| business KYC | Verify applicant identity from business KYC, then test the same applicant file against Udyam certificate. Save the checked CGTMSE loan guarantee checklist 2026 evidence with the final acknowledgement. |
| Udyam certificate | Udyam certificate should support the live application answer about eligibility status. For CGTMSE loan guarantee checklist 2026, use the format and issuing record named in the current authority instruction. |
| financial statements | Financial statements should support transaction or activity details exactly as entered. Compare any different name, date, identifier, or status with loan application before submission. |

## CGTMSE: confirm the live route and applicant fit

MSME borrowers should use loan application to establish the starting facts for CGTMSE, then compare business KYC and Udyam certificate with the current route shown by CGTMSE official portal.

## Udyam certificate conflict: decide before upload

If loan application and business KYC disagree, the CGTMSE file no longer demonstrates that the applicant, activity, funding need, and supporting records satisfy the live route; resolve the source record before relying on Udyam certificate.

Do not use business KYC to fill a gap that only loan application can answer. Resolve the difference, record what Udyam certificate proves, and retain financial statements.

## MSME borrowers: verify the authority route

Record the official page used for CGTMSE, the date it was checked, and the unresolved question involving Udyam certificate; keep that note with financial statements.

| Official reference | What to confirm |
| --- | --- |
| [myScheme - official government scheme discovery portal](https://www.myscheme.gov.in/) | Use the listing to find the official application owner for MSME borrowers, then verify the current process and accepted evidence on that authority's page. |
| [CGTMSE official portal](https://www.cgtmse.in/) | Confirm whether the authority currently accepts business KYC for CGTMSE and note any portal, location, or timing restriction. |
| [Udyam Registration official portal](https://udyamregistration.gov.in/) | Read the current instructions before upload, then compare the required Udyam certificate with financial statements in the CGTMSE file. |

## financial statements case check: reconstruct the answer

CGTMSE is ready for a case check when MSME borrowers can explain the applicant fact, the accepted source record, the open issue, and the purpose of financial statements.

Having loan application, business KYC, and Udyam certificate ready does not resolve a contradiction among them. The unresolved CGTMSE loan guarantee checklist 2026 fact should name the issuing record, correction owner, and evidence required before submission.

## CGTMSE finance application: evidence limits and retention

A document-readiness review for CGTMSE does not replace the live instruction or decide a disputed legal, ownership, payment, or eligibility issue for MSME borrowers.

If Udyam certificate still leaves a material answer unsupported, MSME borrowers should pause the finance application; otherwise retain financial statements and the application acknowledgement together.
