# eShram Card Registration Checklist for Unorganised Workers

eShram Card Registration Checklist for Unorganised Workers starts with three concrete checks: whether Aadhaar identifies the right applicant, bank account supports the claimed condition, and mobile number fits the current instructions on eShram official portal.

## EShram: confirm the live route and applicant fit

EShram fits unorganised workers only if the live authority route and the applicant records describe the same request; start with Aadhaar, test bank account, and note what mobile number still leaves unresolved.

## Unorganised workers: map Aadhaar to occupation details

Unorganised workers should read Aadhaar, bank account, mobile number, and occupation details as a connected record set, but preserve the separate purpose and issuing source of each item.

| Record | What it must support |
| --- | --- |
| Aadhaar | Read Aadhaar only for applicant identity. If bank account points to a different applicant fact, pause the request and resolve that difference first. |
| bank account | Bank account should be current, legible, and linked to the same applicant as mobile number. Retain the version used for the submission. |
| mobile number | Record what mobile number proves about verification and alert details, then compare that answer with occupation details. For eShram card registration 2026, use each record only for the fact it actually contains. |
| occupation details | Occupation details should answer the application question about trade, occupation, or business-activity details. Where it disagrees with Aadhaar, identify the authoritative record before uploading. |

## mobile number conflict: decide before upload

A material difference between Aadhaar and bank account can change the eShram request; record the affected answer, the owner of the correction, and the limited role of mobile number.

The eShram request should not contain a fact that neither Aadhaar nor bank account supports. Correct the source record or obtain an accepted alternative for mobile number before submission.

## occupation details case check: reconstruct the answer

A later verification request should be answerable from the file itself, so use Aadhaar to establish the starting fact, mobile number to explain any change, and occupation details to preserve the outcome.

Before submitting the eShram request, test whether Aadhaar and bank account cover the required facts. If mobile number still leaves an answer unsupported, identify an accepted record and keep occupation details with the request acknowledgement.

## Unorganised workers: verify the authority route

Reopen the official eShram route immediately before upload and preserve the instruction that supports Aadhaar; an old form or discovery-page summary should not override the live page.

| Official reference | What to confirm |
| --- | --- |
| [myScheme - official government scheme discovery portal](https://www.myscheme.gov.in/) | Treat this as the discovery route for eShram: identify the department, current channel, and records that need confirmation on the scheme's own portal. |
| [eShram official portal](https://eshram.gov.in/) | Verify the conditions, document format, submission route, and follow-up channel that apply to bank account for unorganised workers. |

## eShram request: evidence limits and retention

Location, applicant facts, and submission date may change the eShram route for unorganised workers; unresolved ownership, legal, tax, or eligibility questions need authority guidance or suitable professional advice.

After the request, unorganised workers should monitor the channel shown on the request acknowledgement and preserve every clarification request with occupation details.
