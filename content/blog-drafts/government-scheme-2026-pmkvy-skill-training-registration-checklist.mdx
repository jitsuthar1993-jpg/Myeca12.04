# PMKVY Skill Training Registration Checklist for Job Seekers

PMKVY preparation is a fit-and-evidence decision for job seekers and skill learners; the work is to check identity, training centre, course fit, and certificate records, compare Aadhaar with mobile number, and retain education proof and bank details if required for follow-up.

## PMKVY: confirm the live route and applicant fit

Before a PMKVY request, job seekers and skill learners should write down the intended outcome, open [Skill India Digital official portal](https://www.skillindiadigital.gov.in/), and decide whether the identity, status, and registration details are supported from Aadhaar, mobile number, and education proof.

## bank details if required case check: reconstruct the answer

Bank details if required should make the completed request easier to reconstruct; if Aadhaar and mobile number still conflict, the file is not ready for that step.

Before submitting the PMKVY request, test whether Aadhaar and mobile number cover the required facts. If education proof still leaves an answer unsupported, identify an accepted record and keep bank details if required with the request acknowledgement.

## Job seekers and skill learners: map Aadhaar to bank details if required

Mobile number should not be used as a substitute for Aadhaar; assign education proof and bank details if required their own application questions so the PMKVY request can be reconstructed later.

| Record | What it must support |
| --- | --- |
| Aadhaar | Read Aadhaar only for applicant identity. If mobile number points to a different applicant fact, pause the request and resolve that difference first. |
| mobile number | Mobile number should be current, legible, and linked to the same applicant as education proof. Retain the version used for the submission. |
| education proof | Record what education proof proves about education, institution, course, or training details, then compare that answer with bank details if required. For PMKVY registration documents 2026, use each record only for the fact it actually contains. |
| bank details if required | Bank details if required should answer the application question about payment-account details. Where it disagrees with Aadhaar, identify the authoritative record before uploading. |

## education proof conflict: decide before upload

Treat a missing Aadhaar differently from a contradictory mobile number: the first may need an accepted alternative, while the second needs correction or authority guidance before uploading education proof.

The PMKVY request should not contain a fact that neither Aadhaar nor mobile number supports. Correct the source record or obtain an accepted alternative for education proof before submission.

## Job seekers and skill learners: verify the authority route

Reopen the official PMKVY route immediately before upload and preserve the instruction that supports Aadhaar; an old form or discovery-page summary should not override the live page.

| Official reference | What to confirm |
| --- | --- |
| [myScheme - official government scheme discovery portal](https://www.myscheme.gov.in/) | Confirm the administering authority for PMKVY and its live department link before relying on the eligibility or document summary. |
| [Skill India Digital official portal](https://www.skillindiadigital.gov.in/) | Confirm the current category for job seekers and skill learners, accepted mobile number, application channel, and any live deadline; compare those instructions with education proof. |

## PMKVY request: evidence limits and retention

Aadhaar, mobile number, education proof, and bank details if required can establish a reviewable file for PMKVY, but the current authority conditions still decide eligibility and outcome.

Before the request, review the applicant details, accepted Aadhaar, role of education proof, and contact information; save bank details if required with the request acknowledgement.
